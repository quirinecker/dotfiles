# Quirin Ecker Dotfiles

This repository does not actually contain my dotfiles, because my actual dotfiles themselves are private. However it does contain a documentation in this readme detailing how to get nearly the same configuration (minus the private parts)

## The parts that are publically available

* .dotfiles-modules: Contains modules i use in my actual dotfiles. Contain all the configuration that is not specific to me
* .dotfiles-template (WIP, not available yet): Contains a template that imports all the modules declared in `.dotfiles-modules`.

## Why are the dotfiles private

My actual dotfiles contain private information and aren't even really that usable for anyone but me. Instead i focuesd on providing reusable modules that can be found in the `.dotfiles-modules` repository.
